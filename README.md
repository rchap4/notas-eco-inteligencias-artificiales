# Resources to Understand Artificial Intelligence (IA) and the Environment

[EcoLogits Calculator](https://calculator.ecologits.ai)
> Understand a Large Language Model's (LLM) ecological footprint and compare different models to make
> informed decisions when choosing to use IA with intention.

[Your Digital Life](https://your-digital-life.org)
> More than just your IA usage, looking at the carbon and water footprint across
> all the datacenter and compute backed technologies you may use (e.g., social media
> streaming media, office emails).

[EcoLogits packages for Python and JavaScript](https://ecologits.ai/latest/)
> Use EcoLogits with Python or JavaScript running inference with cloud IA models.

[Code Carbon](https://codecarbon.io)
> Track the ecological footprint of your code or when running LLM and ML models locally.
